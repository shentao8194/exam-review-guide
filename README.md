# Exam Review Guide

A Codex skill for creating and revising focused exam-preparation guides from course schedules, syllabi, lecture materials, notes, question banks, and past exams.

The workflow aligns chapter order with the stated exam scope, pairs source diagrams with clear explanations, verifies question coverage and answers, and produces a reviewed PDF with its complete LaTeX source project.

## Contents

- `SKILL.md` — skill description, routing, and core workflow.
- `references/production-guide-and-prompt-template.md` — project structure, LaTeX setup, examples, question workflow, and a reusable prompt.
- `references/content-and-visual-layout.md` — editorial, image, table, source-preservation, and page-review standards.

## Install

Place the `exam-review-guide` directory in your Codex skills directory. Codex can then use the skill when you ask it to create, revise, or complete an exam review guide.

## Language

All documentation and prompt templates are written in English. The resulting study guide should use the language requested by the user and supported by the source materials.
